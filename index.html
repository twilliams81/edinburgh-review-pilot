What the demonstration provides

  1. Readable articles: individual texts separated from scanned journal issues.

  3. Traceable sources: archive identifiers, source links and file hashes.

Source scans remain hosted by the Internet Archive. This package contains text derivatives and metadata; it does not redistribute scan images.
